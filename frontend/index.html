01

Preprocessing

CLAHE (Contrast Limited Adaptive Histogram Equalization) partitions the thermal image into contextual tiles to prevent over-amplification of noise while balancing wide dynamic range. Bilateral Filtering denoises smooth thermal regions while preserving sharp gradient boundaries.

02

Colorization

Converts preprocessed infrared intensity into chromatic channels. In local mode, scientific pseudocolor palettes map thermal radiometry intuitively. In cloud mode, deep exemplar colorization infers natural perceptual colors.

03

Post-Processing

Unsharp Masking is applied specifically to the luminance channel in LAB color space, accentuating high-frequency boundary contours without introducing color fringing or chromatic artifacts.

04

Evaluation Metrics

Quality is verified without reference bias using Tenengrad Gradient Sharpness, Shannon Information Entropy, Root-Mean-Square Contrast, and the Edge Preservation Index (EPI). Paired full-reference PSNR/SSIM is computed when ground-truth RGB is supplied.
